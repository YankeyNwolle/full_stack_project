# 📚 Blog Full Stack Project

Une application web de blog complète construite avec **Express.js**, **EJS**, et **PostgreSQL**.

## ✨ Fonctionnalités

- 👥 **Gestion des utilisateurs** - Inscription, connexion, profil utilisateur
- 📝 **Créer des posts** - Titre, image, contenu avec possibilité de modifier
- 💬 **Commentaires** - Commenter les posts d'autres utilisateurs
- 📂 **Sections (Boards)** - Organiser les sujets par catégories
- 🔧 **API REST** - Endpoints complètes pour toutes les opérations
- 🎨 **Interface moderne** - Design responsive et élégant

## 🛠️ Technologies

### Backend
- **Node.js** - Runtime JavaScript
- **Express.js** - Framework web
- **PostgreSQL** - Base de données
- **EJS** - Moteur de templating

### Frontend
- **HTML5** - Structure
- **CSS3** - Styling
- **Bootstrap** - Framework CSS
- **JavaScript** - Interactivité

## 📋 Prérequis

- Node.js v14+
- npm ou yarn
- PostgreSQL 12+
